# Results report

## Scope
This report identifies observed overlap between reported microplastic concentration and observed species richness in a common Indian Ocean grid. It does not infer causality.

## Dataset and grid summary
Grid cells: 45720
Cells with both observation layers: 15533

## Hotspot results
Pollution hotspots: 3100
Biodiversity hotspots: 3097
Effective hotspots: 745

## Limitations
Uneven sampling, temporal mismatch, heterogeneous microplastic methods, the chosen grid resolution, and occurrence-record bias can affect these observed patterns. Missing records remain missing; they are never treated as zero.
